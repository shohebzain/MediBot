# 🏥 MediBot – AI Hospital Assistant


**MediBot** is an AI-powered healthcare chatbot designed to assist patients and healthcare providers with quick, reliable, and intelligent medical support. Built using **React**, **Tailwind CSS**, and **Google GenAI**, MediBot provides a simple and intuitive interface for symptom checking, appointment scheduling, and medication reminders - all in one place.


🔗 **Live Demo:** [https://lightcyan-curlew-282529.hostingersite.com/](https://lightcyan-curlew-282529.hostingersite.com/)


## 🚀 Features

* 💬 **AI Chat Assistant** – Understands patient queries using Google GenAI and responds conversationally.
* 🩺 **Symptom Checker** – Helps users identify possible conditions and suggests next steps.
* 📅 **Appointment Scheduling** – Assists with booking or rescheduling doctor appointments.
* 💊 **Medication Reminders** – Keeps track of prescriptions and notifies users on time.
* 🏥 **Hospital Information Access** – Shares department info, visiting hours, and contact details.
* 🌐 **Responsive Design** – Works seamlessly on desktop and mobile.
* 🔒 **Privacy-Focused** – Designed to handle user interactions securely and confidentially.

## ⚙️ Installation & Setup

To run MediBot locally:

```bash
# Clone the repository
git clone https://github.com/shohebzain/MediBot.git

# Navigate to the project directory
cd MediBot

# Install dependencies
npm install

# Start the development server
npm run dev
```

To build for production:

```bash
npm run build
```

Then deploy the contents of the **dist** folder to any static hosting provider (like Hostinger, Netlify, or Vercel).
